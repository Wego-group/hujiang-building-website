# 沪江建筑企业官网

以现代工业建筑与钢结构工程为核心的响应式企业网站。页面包含企业介绍、业务领域、项目案例、交付流程、新闻洞察与项目咨询等完整模块。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000` 即可预览。

## 构建检查

```bash
npm run build
npm test
```

## 内容替换

请查看项目根目录中的 `内容替换说明.md`。网站里带“示例”字样的电话、邮箱、地址、项目、数据与链接均为占位内容。

主要页面文件：

- `app/page.tsx`：页面文案与结构
- `app/globals.css`：视觉样式与响应式布局
- `public/images/hero.png`：首屏和案例示例图

咨询表单当前仅展示界面，不会发送数据。正式上线前需接入企业邮箱、CRM 或表单服务。
